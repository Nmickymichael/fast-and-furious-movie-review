# Fast & Furious Movie Reviews

A movie-themed website dedicated to the Fast & Furious franchise, showcasing its iconic characters, movie reviews, and memorable moments.

## 🚗 Project Overview

This project explores the Fast & Furious universe through a visually engaging website designed for movie enthusiasts.

## ✨ Features

- Movie reviews and ratings.
- Character showcases and profiles.
- Fast & Furious franchise highlights.
- Responsive and user-friendly interface.
- Movie-themed visual design.
- Animated starfield background and scroll reveal effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
